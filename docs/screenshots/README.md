# Documentation Screenshots Directory

This directory stores reference architecture diagrams, UI captures, and verification snapshots:

Recommended screenshots to store here:
1. `mailpit-inbox.png`: Mailpit web UI showing rendered payment reminder emails.
2. `functions-local-run.png`: Terminal output running `func start` with active endpoints.
3. `apim-portal-test.png`: APIM developer portal / test console showing successful API calls.
4. `database-erd.png`: Entity-relationship diagram of tables in Azure Data Studio or SSMS.
5. `logicapp-run-history.png`: Azure Logic App workflow run history and execution branches.
